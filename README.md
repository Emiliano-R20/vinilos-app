# Vinilos App

Full-stack web app to browse and manage a vinyl collection. Built as a hands-on project to practice React 19 and Node.js/Express during my first year of Software Engineering.

---

## Status: Work in Progress 

This is an active project where I'm applying what I learn every day.

- [x] **Frontend:** Base UI and components built with React 19 + Vite.
- [x] **Backend:** Express server set up with basic API routes.
- [ ] **Database:** MongoDB integration for real data persistence (In progress).
- [ ] **Styling:** Native CSS (Planning to move to Tailwind CSS).
- [ ] **Auth:** User login and protected routes.

---

## About this project
I started this project to get real hands-on experience connecting a React frontend with an Express backend, practicing Git workflows, and building clean, modular code. Just to learn :D.
